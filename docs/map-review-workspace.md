# Map-centred registry review

The desktop workspace has three columns in one row: the MaStR registration browser, a taller image map, and the association/image inspector. Lists and the inspector scroll independently. Statistics, acquisition jobs and the image-region queue are collapsed by default so that they do not precede the map as large panels.

1. Select a registry record on the left. The right inspector immediately displays its detailed registration, without requiring a map selection: technical specifications, operating/registration dates, directions and inclinations, public location information, source identifiers, storage relationships and an expandable original-field table. Missing location data is labelled as unavailable. The map fits numbered image alternatives and any saved, non-rejected associations. A separate button locates a public registry coordinate when one exists.
2. Click an image candidate point. The corresponding PV array opens on the map and in the right-hand inspector. Number shortcuts in the left selection card provide access when markers overlap.
3. Inspect **Saved links**, **Potential matches** or **Other reviews** on the right. Selecting a different registry partner there changes the proposed pair, while preserving the left-hand search and candidate map. Saved probable/verified links retain explicit state labels; a probable link is not a verified identity.
4. Use the **Image review** tab to confirm PV presence/mounting or edit the source regions. The **MaStR matching** tab owns the independent identity decision. Existing evidence, source-version checks, ambiguity and stale-proposal protection remain in force.
5. Saving refreshes the relevant link lists and map marker state. The export action remains available in the inspector. Review writes are not performed merely by browsing or selecting a marker.

Selecting a map candidate opens association review. The registration-details and association buttons let the reviewer switch back and forth without discarding an unsaved identity draft or replacing the current map selection. Clicking the currently selected registry row reopens its details. Details scroll inside the right inspector and do not reduce the map height.

Amber markers are potential image locations; blue marks probable saved associations; green marks verified identities; grey indicates uncertain or stale evidence. Numbers identify displayed examples, not proven identity ranks. Points come from the image array geometry, never an invented coordinate on an anonymous MaStR record. The default list displays at most five stored scoring examples plus saved associations; full candidate-pool and tied-best counts remain visible.

The map drawing surface now has a 600 px minimum height and the desktop review row a minimum height of 850 px. The page allows more width for the map and compresses the upper heading/context. **Expand map** fills the viewport; **Restore map** or Escape exits, while retaining the current selection and draft. Existing viewport geometry limits, request cancellation and source-image tile caching remain active.

Validation: 44 Python tests and 15 React interaction tests passed, with a TypeScript/Vite production build. Checks cover registration-to-map-to-inspector selection, immediate detail display, switching records without stale fields, draft retention while viewing details, switching potential partners without replacing the search record, association save/list refresh, reviewer requirements, saved-association filtering and stale image evidence.
