Recognition method

DeepLabV3+ / RegNetY-080 uses pinned RGBI and RGB checkpoints. Inputs are uint8, divided by 255; RGB uses ImageNet normalization and NIR uses mean 0.5 / standard deviation 0.25. Native windows are 256 pixels with 24-pixel overlap, sigmoid of output channel 1, arithmetic-mean blending and threshold 0.5. Four-neighbor components smaller than 25 pixels are removed only after cross-block stitching. Horizontal projected area is not module surface area.

Municipal processing uses a world-anchored 232-pixel stride and bounded context blocks. This global window origin differs from the earlier crop-relative experiment. CPU/MPS probe results and runtime settings are retained in the inference provenance. Model scores are uncalibrated.

Quality and interpretation

  • Candidate counts do not measure precision or recall.

  • Inspect model-negative roofs through the checked-area workflow to discover missed PV.

  • Shared-edge stitching preserves four-neighbor connectivity; diagonal point contacts are kept separate.
  • Both model outputs remain separate; model agreement does not automatically confirm a candidate.
  • Imagery newer than the frozen capture dates requires a new run; existing manual decisions are not silently migrated.
