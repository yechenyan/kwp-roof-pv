Interpretation limits

  • Eight convenience crops: four targeted positives and four reference-empty images; 10 reference components.
  • One crop contributes 89.28% of positive pixels. Micro IoU therefore strongly reflects that crop.
  • RGB pixel IoU: 0.8961; RGBI: 0.8742. Equal-positive-image IoU: RGB 0.8171; RGBI 0.8466. RGBI also has lower area MAE.
  • Public source scenes center on ≥30 kWp plants. Local under-30 kW accuracy still needs spatially independent annotation.
  • RGBI has an extra NIR channel; it is a separate enhanced-input comparison, not an RGB-only entrant.
  • GPT boxes are not pixel masks. SAM 3 access was blocked. Neither receives an invented pixel score.
  • Observed runtimes were concurrent and are not an isolated speed ranking.
