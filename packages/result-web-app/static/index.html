HOW TO READ THE ATLAS

A transparent result,
with uncertainty attached.

01 / Technical ranking

Continuous area compatibility uses registered power, module count, installation era and categorical tilt. Building overlap and model agreement add image evidence. Public coordinates, when available, constrain the search.

02 / Explicit allocation

Later installations use a separate roof-capacity allocation. Shared image selections remain visible as competition. No automatic selection is promoted to verified identity.

03 / Reusable delivery

EPSG:3035 GeoPackage layers retain technical registry fields, association reasons and storage relationship tables. Storage totals use unique equipment IDs.
